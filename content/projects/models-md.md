A small plugin for [opencode](https://opencode.ai) that helps manage Model
Context Protocol (MCP) server configurations. It reads MCP server definitions
from your opencode setup and makes them available as structured markdown — useful
for documenting, sharing, or version-controlling your AI tool configurations.

Source: [github.com/acramsay/dotfiles](https://github.com/acramsay/dotfiles/tree/main/home/.config/opencode/plugins/models-md)
